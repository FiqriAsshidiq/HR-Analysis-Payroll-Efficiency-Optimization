# HR Analysis: Payroll & Efficiency Optimization

Proyek ini mendemonstrasikan kemampuan mengolah dataset besar untuk menganalisis efisiensi biaya lembur dan performa karyawan di berbagai departemen.

## Masalah Bisnis
- Mengidentifikasi pembengkakan biaya gaji akibat jam lembur.
- Menemukan korelasi antara jam kerja tambahan dengan output yang dihasilkan.
- Menghitung "Cost per Task" untuk mengukur efisiensi individu dan departemen.

## Teknologi yang Digunakan
- Python (Pandas & NumPy)       : Pengolahan data skala besar dan pembuatan data dummy.
- Matplotlib & Seaborn          : Visualisasi distribusi gaji dan analisis outlier (Boxplot).
- Openpyxl                      : Automasi laporan ke format Excel (.xlsx).

## Fitur Utama
- Automated Payroll Calculation : Menghitung lembur secara otomatis berdasarkan regulasi jam kerja (160 jam/bulan).
- Efficiency Scoring            : Menghitung rasio biaya terhadap hasil kerja (Cost per Task).
- Departmental Summary          : Ringkasan biaya dan produktivitas per departemen.
